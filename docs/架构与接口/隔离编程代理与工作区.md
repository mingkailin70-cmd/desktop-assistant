# 隔离编程代理与工作区

更新：2026-09-30。本文说明首个可运行的编程代理切片及其明确边界。代码已接入 WPF 设置、`ToolBroker`、本地推理客户端和任务状态；编译成功不等于本机模型效果、安全红队或 P0 代码任务门槛已通过。

## 用户流程

1. 在小K设置中选择本次允许处理的项目目录，并设置仓库外的隔离工作区目录。两者不能相同或相互包含；数据、模型、评测与隔离工作区目录也必须分开。
2. 重启小K后输入编程任务。项目根目录来自设置，不接受模型给出的路径。
3. 小K把项目复制到一个新任务目录中的 `baseline` 与 `workspace`。原项目只读；补丁只写入该任务的 `workspace`。
4. 本地模型先从受支持文本文件清单选最多4个文件，再基于选中的内容生成完整文件修改。`ToolBroker` 拒绝清单以外的路径、重复路径、越界路径、过大结果和删除请求。
5. 小K显示修改差异并把任务记为 `awaiting_approval`。这代表等待用户审阅，不代表已合入。当前没有自动复制回原项目、提交或推送功能。

## 文件范围与上限

- 每份快照最多复制 4000 个普通文件、512 MiB；项目会保留一份只读基线和一份工作副本，因此每个任务最多占用约1 GiB，单文件超过16 MiB会跳过。工作区最多保留5个任务目录。遇到 `.git`、构建产物、缓存和常见凭证目录会跳过；`.env`、密钥、证书、常见凭证文件名也会跳过。复制、读取基线和写入工作副本均做 Windows 句柄最终路径校验；源文件若检测到多个硬链接则拒绝任务，防止项目内别名引用目录边界外的同一文件；模型不能给出文件路径权限。
- 为避免任务快照持续占满磁盘，工作区最多保留5个任务目录。达到上限后，小K停止创建新任务；用户需先自行检查并删除旧任务。
- 提供给模型的文件类型限于常见源码、项目配置与文档扩展名；单个文本文件最多256 KiB，清单最多12,000字符，选择最多4个文件，发送给生成步骤的源文件总量最多10,000字符，补丁最多40,000 UTF-8字节，界面差异最多显示30,000字符。
- 工作区基于选择时的磁盘内容，不是 Git commit，也不会继承 `.git`、未提交状态记录或构建输出。任务期间改变的源文件会使快照创建失败；过大的文件或不支持的编码/类型不会交给模型。
- 模型步骤只有文字输入与 JSON 输出；本切片不注册 shell、脚本、联网、删除、Git、任意路径写入或合并工具。模型只修改已选中的现有文件。

## 状态与隐私

任务记录只保存随机任务编号、时间、目录和状态，不保存用户编程指令、模型提示、源文件内容或差异正文。隔离目录包含所选项目的普通文件快照和生成后的修改，保存在用户指定的本机目录；用户可通过资源管理器检查或自行删除。当前没有自动清理功能。

常见凭证路径与文件名会排除，文本内容也会扫描若干常见密钥格式并跳过疑似命中文件。这不是完整的凭证检测：代码文件里直接写入的未知格式密钥或其他敏感文本仍可能被模型看到。首次使用前应移除项目中的真实凭证；代码任务的凭证检测还需经专门测试和强化。
