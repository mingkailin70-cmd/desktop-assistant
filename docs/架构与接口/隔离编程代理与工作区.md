# 隔离编程代理与工作区

更新：2026-09-30。本文说明首个可运行的编程代理切片及其明确边界。代码已接入 WPF 设置、`ToolBroker`、本地推理客户端和任务状态；编译成功不等于本机模型效果、安全红队或 P0 代码任务门槛已通过。

## 用户流程

1. 在小K设置中选择本次允许处理的项目目录，并设置仓库外的隔离工作区目录。两者不能相同或相互包含；数据、模型、评测与隔离工作区目录也必须分开。
2. 重启小K后输入编程任务。项目根目录来自设置，不接受模型给出的路径。
3. 小K把项目复制到一个新任务目录中的 `baseline` 与 `workspace`。原项目只读；补丁只写入该任务的 `workspace`。
4. 本地模型先从受支持文本文件清单选最多4个文件，再基于选中的内容生成完整文件修改。两次模型调用均作为后台步骤独立取得并释放 `ModelBroker` 租约，交互请求可在步骤边界优先运行。`ToolBroker` 拒绝清单以外的路径、重复路径、越界路径、过大结果和删除请求。
5. 小K先显示完整差异、原项目与隔离工作区路径。关闭或选择“保留补丁，不运行”会把任务记为 `awaiting_approval`，不触发命令。
6. 只有快照根目录存在唯一 `.sln`、`.slnx` 或 `.csproj` 且本机找到 `dotnet.exe` 时，审阅窗才显示两条固定命令：`dotnet restore <目标> --configfile <小K生成的仅 nuget.org 配置> --packages <隔离工作区缓存>`，随后 `dotnet test <目标> --no-restore`。用户必须单独点击批准；取消或关闭默认保留补丁，不执行命令。任意 shell、模型提供的命令、工作区外目标、Git 操作和自动合并均不开放。
7. 两条固定命令都在 Windows AppContainer 中运行：只给任务工作区临时写权限，只给固定 .NET 运行时临时读权限；AppContainer 身份与这些 ACL 在命令结束时尝试回收。进程放入 Host 退出即回收的 Job Object。`dotnet test` 不配置网络能力；`dotnet restore` 配置 `internetClient`，NuGet 源仅为 nuget.org，但 MSBuild 项目目标仍可能使用这项联网能力。每条命令最多运行3分钟，取消/超时会结束进程树；AppContainer 准备失败时拒绝运行，不回退到普通进程。验证结束后任务仍为 `awaiting_approval`，这不代表补丁通过验收或已合入。

## 最近任务与重启后的检查

桌面窗口的“记录”按钮和托盘菜单的“最近任务”会列出最近的任务类别、状态、更新时间及隔离编程工作区路径。读取器只从状态文件提取允许展示的状态和时间字段，忽略其他字段；路径通过目录句柄和最终路径边界检查后才会显示。原始请求、模型提示、差异正文和通知内容不会进入历史列表。路径以只读文本框显示，用户可复制到资源管理器手动检查。

此入口只是定位已有任务数据，不会自动续跑、重复调用模型、重放工具步骤或合并差异。历史视图按当前 Host 启动时间判断：此前仍处于 `planning` 或 `running` 的隔离编程任务显示为“上次中断，需核对”，并保留工作区路径供用户检查；底层状态文件保持只读，不会被启动流程改写。当前没有真实模型进程故障后的自动恢复保证。用户检查工作区后，可自行决定继续手工处理或删除任务目录。

## 文件范围与上限

- 每份快照最多复制 4000 个普通文件、512 MiB；项目会保留一份只读基线和一份工作副本，因此每个任务最多占用约1 GiB，单文件超过16 MiB会跳过。工作区最多保留5个任务目录。遇到 `.git`、构建产物、缓存和常见凭证目录会跳过；`.env`、密钥、证书、常见凭证文件名也会跳过。复制、读取基线和写入工作副本均做 Windows 句柄最终路径校验；源文件若检测到多个硬链接则拒绝任务，防止项目内别名引用目录边界外的同一文件；模型不能给出文件路径权限。
- 为避免任务快照持续占满磁盘，工作区最多保留5个任务目录。达到上限后，小K停止创建新任务；用户需先自行检查并删除旧任务。
- 提供给模型的文件类型限于常见源码、项目配置与文档扩展名；单个文本文件最多256 KiB，清单最多12,000字符，选择最多4个文件，发送给生成步骤的源文件总量最多10,000字符，补丁最多40,000 UTF-8字节，界面差异最多显示30,000字符。
- 工作区基于选择时的磁盘内容，不是 Git commit，也不会继承 `.git`、未提交状态记录或构建输出。任务期间改变的源文件会使快照创建失败；过大的文件或不支持的编码/类型不会交给模型。
- 模型步骤只有文字输入与 JSON 输出；本切片不注册 shell、脚本、模型控制的联网、删除、Git、任意路径写入或合并工具。模型只修改已选中的现有文件。外部依赖还原只由审阅窗提供固定命令并单独征得用户确认。

## 状态与隐私

任务记录只保存随机任务编号、时间、目录和状态，不保存用户编程指令、模型提示、源文件内容或差异正文。隔离目录包含所选项目的普通文件快照和生成后的修改，保存在用户指定的本机目录；用户可通过资源管理器检查或自行删除。当前没有自动清理功能。

常见凭证路径与文件名会排除，文本内容也会扫描若干常见密钥格式并跳过疑似命中文件。这不是完整的凭证检测：代码文件里直接写入的未知格式密钥或其他敏感文本仍可能被模型看到。首次使用前应移除项目中的真实凭证；代码任务的凭证检测还需经专门测试和强化。
