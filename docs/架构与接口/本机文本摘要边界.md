# 本机文档摘要边界

## 目的与当前状态

小K只读取用户明确指定、位于设置搜索目录中的单个本机文本/源码、`.docx` 或 `.pdf` 文件，并将受限正文交给已配置的本地模型生成摘要。不会搜索或顺带读取其他文件、打开 Office/PDF/浏览器、执行文档内命令，也不会根据正文授权其他工具。

## 固定工具契约

| 字段 | 固定值 |
| --- | --- |
| 工具ID | `file.summarize.text.v1` |
| 参数 | 唯一参数 `path`，来自用户明确给出的路径 |
| 目标 | `user-files`，只对应设置中配置的本机搜索目录 |
| 前置条件 | `ConfiguredSearchRoot` |
| 预期结果 | `LocalDocumentTextExtracted` |
| 执行模式 | 后台只读；不切换窗口、不模拟鼠标键盘 |

用户可输入“总结文本文件：完整路径”“总结DOCX文件：完整路径”或“总结PDF文件：完整路径”；也支持相应的“概括”前缀及通用“总结文件/概括文件”前缀。命令必须包含有效路径。缺少路径、网络/UNC路径、搜索根外路径或提案目标不匹配时失败关闭。

## 文件读取限制

- **文本/源码：**只接受内容搜索策略登记的扩展名，例如 `.txt`、`.md`、`.csv`、`.log`、常见编程语言源码和配置文件；文件最多 64 KiB。必须能按严格文本编码解码，拒绝不支持编码和二进制零字节。
- **DOCX：**只接受 `.docx`，不接受 `.doc`、`.docm` 或其他 Office 格式。ZIP 最多 8 MiB、512 个条目；必须恰有一个 `word/document.xml`，解压后最多 1 MiB，提取正文最多 64 KiB。仅在内存中解析主文档段落、制表符和换行；禁止 DTD，关闭外部 XML 解析器。不处理关系、链接、宏、附件、图片 OCR、批注、页眉页脚或嵌入对象。
- **PDF：**只接受最多 8 MiB 的 `.pdf`，最多 100 页，解析所得可选择文字最多 64 KiB。使用锁定的 PdfPig `0.1.16` 和内容阅读顺序提取器；严格解析并设置最大递归栈深度64。解析器不执行 PDF JavaScript，不读表单、批注或附件，不修改文件，不做 OCR。没有可选择文字的扫描件返回空正文，不声称已识别图像。
- **PDF资源与取消：**PdfPig 没有对解压后流总量的独立硬性预算，因此不在主 Host 进程解析。单次子进程最多 512 MiB 进程内存、运行最多20秒、优先级低于正常任务；Host 在写入输入前先将进程纳入 Windows Job Object，若不能建立限制就拒绝解析。取消/超时会终止该子进程；每次任务只解析一个 PDF，完成后退出。
- **路径和稳定性：**读取前核实文件为普通本机文件且最终路径位于配置搜索根内，通过已打开的句柄读取，并在读取后核对长度与修改时间。拒绝网络路径、链接/重解析点/特殊文件；文件读取时发生变化则丢弃正文。
- **数据驻留：**正文仅在当前任务与 PDF 子进程的内存/管道中短暂存在，不落盘，不写 SQLite 任务历史、工具日志或错误文本。工具结果只含固定状态类别和正文供当前本机推理使用。

## 本地推理和不可信输入

Host 通过 `ModelBroker.RunInteractiveAsync` 使用已配置的本地模型；不提供云端回退。长文按最多 6,000 字符分段、最多16段，最终合并同样受固定摘要长度限制。正文放入 JSON 的 `untrusted_document_content` 字段，分段摘要仍视为不可信数据。系统提示禁止遵从文档里的指令、调用工具、联网、修改文件或发送消息。摘要不会产生新的操作授权，也不会自动读取同目录其他文件。

模型离线、超时、取消或返回空结果时，小K只反馈当前任务失败/取消，不保存原文、不切换到云服务、不重放用户动作。由于当前独显可用显存低于模型启动门槛，本阶段未启动候选模型；以上代码与合成输入测试不代表摘要质量、模型延迟或 GPU 资源达到目标。
