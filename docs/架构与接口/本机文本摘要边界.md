# 本机文本文件摘要边界

## 目的与当前状态

本能力只处理用户明确指定、位于设置搜索目录中的单个本机文本/源码文件或 `.docx` 文档，并通过已配置的本地模型生成摘要。它不会搜索或读取未指定文件，不会打开 Office、PDF 或浏览器，不会执行文件内的命令，也不会根据文件正文触发其他工具。

0.1.81.0已将安全的 DOCX 主文档文字提取接入现有摘要工具，并安装签名MSIX。文本/源码文件限制为64 KiB；DOCX限制为8 MiB归档、512个条目、1 MiB主文档XML和64 KiB提取文字。只解析唯一的 `word/document.xml`，不解压到磁盘、不处理外部关系、宏、嵌入对象或其他Office格式。受限 .NET 验证器设置`DOTNET_HOST_PATH`指向仓库固定运行时后，完整Windows安全套件119项通过、0项跳过，含AppContainer离线还原与执行；桌面体验检查76项通过。签名MSIX安装及隔离后台启动/正常退出已验收。真实模型、实际摘要质量、推理时延和普通界面操作仍未验收。

## 固定工具契约

| 字段 | 固定值 |
| --- | --- |
| 工具ID | `file.summarize.text.v1` |
| 参数 | 唯一参数 `path`，由用户命令解析 |
| 目标 | `user-files`，只对应设置中配置的本机搜索目录 |
| 前置条件 | `ConfiguredSearchRoot` |
| 预期结果 | `LocalTextFileRead` |
| 执行模式 | 后台只读；不切换窗口、不模拟鼠标键盘 |

命令入口为“总结文本文件：完整本机路径”；另支持“概括文本文件”“总结文本文档”“概括文本文档”“总结文件”“概括文件”前缀。命令必须包含有效路径；缺少路径、UNC/网络路径、路径不在配置根内或提案目标不匹配时失败关闭。

## 读取限制

- 普通文本/源码只接受内容搜索策略登记的扩展名，包括 `.txt`、`.md`、`.csv`、`.log`、常见编程语言源文件及配置文件，最大64 KiB；只接受严格可解码文本，拒绝不支持编码和二进制零字节。
- Office只支持 `.docx`（不是 `.doc`、`.docm` 或其他格式）。压缩归档最大8 MiB、最多512个条目，必须包含且只包含一个精确名为 `word/document.xml` 的主文档项；该项解压后最多1 MiB，提取正文最多64 KiB。超限、损坏或结构不支持时，在模型调用前失败关闭。
- DOCX只从内存中的 ZIP 项解析 WordprocessingML 主文档段落文字、制表符和换行；不会落盘解压。禁止 DTD，关闭 XML 外部解析器；不解析关系文件，不访问超链接，不加载宏、附件、图片、嵌入对象、批注或页眉页脚。
- 读取前核实普通文件及最终路径处于配置搜索根内；通过已打开文件句柄读取，并在读取后核对长度和修改时间。文件在读取过程中变化时丢弃正文并失败；拒绝重解析点/链接文件。
- 文本在当前任务内存中处理。路径和正文不写入 SQLite 任务历史；工具摘要、失败消息和应用日志不包含正文。

## 本地推理与不可信输入

Host 通过 `ModelBroker.RunInteractiveAsync` 调用配置的本地推理客户端，不提供云端回退。长文本按最多 6,000 个字符分段，最多 16 段；每段和最终合并最多使用固定摘要长度。正文放入 JSON 的 `untrusted_document_content` 字段；分段摘要同样按不可信数据传递。系统提示明确禁止遵循文件内指令、调用工具、联网、修改文件或发送消息。摘要结果只是当前任务结果，不是新的操作授权。

模型离线、超时、取消或返回空结果时，不保存原文、不自动切换云服务、不重放用户动作；任务按失败或取消路径反馈。一次摘要不会自动读取同目录其他文件。
