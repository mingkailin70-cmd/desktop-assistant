# 本机文本文件摘要边界

## 目的与当前状态

本能力只处理用户明确指定、位于设置搜索目录中的单个本机文本文件，并通过已配置的本地模型生成摘要。它不会搜索或读取未指定文件，不会打开 Office、PDF 或浏览器，不会执行文件内的命令，也不会根据文件正文触发其他工具。

0.1.80.0 已将该能力接入桌面任务路由与签名 MSIX。源码和安全检查已覆盖正常读取、越界、文件过大、无效编码、长文本分段、取消和任务历史边界；本阶段没有调用真实模型。因此实际摘要质量、推理时延和普通界面操作仍未验收。

## 固定工具契约

| 字段 | 固定值 |
| --- | --- |
| 工具ID | `file.summarize.text.v1` |
| 参数 | 唯一参数 `path`，由用户命令解析 |
| 目标 | `user-files`，只对应设置中配置的本机搜索目录 |
| 前置条件 | `ConfiguredSearchRoot` |
| 预期结果 | `LocalTextFileRead` |
| 执行模式 | 后台只读；不切换窗口、不模拟鼠标键盘 |

命令入口为“总结文本文件：完整本机路径”；另支持“概括文本文件”“总结文本文档”“概括文本文档”“总结文件”“概括文件”前缀。命令必须包含有效路径；缺少路径、UNC/网络路径、路径不在配置根内或提案目标不匹配时失败关闭。

## 读取限制

- 只接受内容搜索策略登记的文本和源代码扩展名，包括 `.txt`、`.md`、`.csv`、`.log`、常见编程语言源文件及配置文件；不支持 PDF、Office 二进制文档、图片 OCR、压缩包或可执行文件。
- 单文件最大 64 KiB；超过上限时不向模型提交正文。
- 只接受严格可解码的文本编码；拒绝不支持的编码、二进制零字节、重解析点/链接文件及不稳定读取。
- 读取前核实普通文件及最终路径处于配置搜索根内；通过已打开文件句柄读取，并在读取后核对长度和修改时间。文件在读取过程中变化时丢弃正文并失败。
- 文本在当前任务内存中处理。路径和正文不写入 SQLite 任务历史；工具摘要、失败消息和应用日志不包含正文。

## 本地推理与不可信输入

Host 通过 `ModelBroker.RunInteractiveAsync` 调用配置的本地推理客户端，不提供云端回退。长文本按最多 6,000 个字符分段，最多 16 段；每段和最终合并最多使用固定摘要长度。正文放入 JSON 的 `untrusted_document_content` 字段；分段摘要同样按不可信数据传递。系统提示明确禁止遵循文件内指令、调用工具、联网、修改文件或发送消息。摘要结果只是当前任务结果，不是新的操作授权。

模型离线、超时、取消或返回空结果时，不保存原文、不自动切换云服务、不重放用户动作；任务按失败或取消路径反馈。一次摘要不会自动读取同目录其他文件。
