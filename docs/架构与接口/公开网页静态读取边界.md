# 公开网页静态与隔离动态读取边界

更新：2026-10-09。本文说明 R3 的网页只读切片。它不提供通用浏览器自动化、登录态访问或前台窗口控制。签名MSIX 0.1.72.0已安装且包内关键程序集与Release发布副本散列一致；尚未启动安装版做真实动态网页读取。

## 用户入口

- `读取网页：https://公开网站/页面`、`查看网页内容 https://...`、`浏览网页 https://...`进入固定工具 `browser.read.public.v1`，JavaScript关闭。
- 只有用户明确写出 `读取动态网页：https://公开网站/页面` 才进入 `browser.read.dynamic.public.v1`。Host只从该命令提取URL，不让模型生成脚本或页面动作。
- URL必须是HTTPS默认端口和DNS主机名；拒绝账号密码、IP字面地址、本机/私有名称及其他协议。

## 共享网络与数据限制

- DNS解析的所有地址都必须通过公网地址策略；连接时重新解析并连接已核验地址。手动处理最多5次HTTPS重定向，每一跳重新检查协议、端口及地址。
- 只读取HTML/XHTML；解压后最多2 MiB，整体时限25秒，输出正文最多16,000字符，ARIA快照最多6,000字符。
- 使用系统 Edge Stable 的隔离无头进程；不复用用户Edge配置、Cookie、缓存、登录态或当前窗口，不下载页面内文件，不把网页副本、正文或ARIA输出写入任务历史。
- 页面标题、正文和ARIA都是不可信网页数据；其中的指令不能改变系统提示、工具权限或用户授权。

## 静态模式

`browser.read.public.v1`禁用JavaScript、Service Worker和所有页面子请求，仅解析用户明确指定网页返回的HTML。可见链接、按钮和表单字段只作为ARIA快照信息读取，不会点击、填写、滚动或提交。

## 隔离动态模式

`browser.read.dynamic.public.v1`只为需要DOM脚本生成的公开页面运行下载HTML里的内联脚本。页面被放入独立 `sandbox="allow-scripts"` iframe，不授予 `allow-same-origin`、表单、下载、弹窗或顶层导航权限；脚本不能访问宿主文档。受控CSP必须在任何下载HTML字节之前生效：允许内联脚本及内联样式，拒绝外部脚本、网络连接、图片/字体以外的子资源、媒体、嵌套框架、对象、表单提交、base URL、Worker和manifest。浏览器上下文还会阻止所有路由请求、Service Worker及下载，关闭弹窗并驳回对话框。两层网络阻断都保留；离线对抗用例包含伪造`<head>`的注释前缀、父文档访问和回环地址请求。

动态模式没有网页账号登录、用户Edge登录态、链接点击、输入框填写、文件上传/下载或表单提交能力。页面若依赖外部API、外部脚本或其他子资源，可能只得到部分DOM或空正文，应返回失败/限制，而不扩大权限。网页脚本和页面仍是不可信代码；动态读取仅限明确URL的短时只读快照。

## 后续扩展门槛

一般浏览器任务需独立设计用户配置档案、站点作用域、DOM目标版本、提交前预览和提交后核验；每种写操作都必须有专用ToolBroker契约和不可伪造的用户授权。匿名读取失败或网站要求前台交互时，应明确回报能力缺口，不得借用用户正在使用的Edge会话。
