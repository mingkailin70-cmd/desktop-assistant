# 公开网页静态读取边界

更新：2026-10-08。本文记录 R3 的浏览器只读源码切片，不表示通用浏览器自动化、登录态访问或安装版验收已经完成。

## 用户入口

当前只接受用户明确输入的“读取网页：https://公开网站/页面”“查看网页内容 https://...”或“浏览网页 https://...”指令。URL 必须是 HTTPS 默认端口、DNS 主机名；拒绝账号密码、IP 字面地址、本机/私有名称及其他协议。该路径是固定 ToolBroker 工具 `browser.read.public.v1`，使用后台执行入口，不调用模型生成浏览器动作。

## 网络和页面边界

- 每次请求先解析 DNS，所有返回地址都必须通过公网地址策略。连接回调重新解析并直接连接已检查的地址，避免在 DNS 校验后通过第二次解析连接到内网地址。
- 手动处理最多5次 HTTPS 重定向；每一跳重新校验协议、端口和地址。读取HTML/XHTML，解压后的正文流最多2 MiB，整体时限25秒，提取文本最多16,000字符。
- 使用系统已安装的 Microsoft Edge Stable，以独立无头进程解析下载到内存的静态 HTML。禁用 JavaScript 与 Service Worker、拒绝浏览器发出的所有页面子请求、禁用下载和 GPU；不复用用户 Edge 配置、Cookie、缓存或登录态，不打开前台窗口，也不保存网页副本。
- 输出包含标题、URL、静态正文和最多6,000字符的 ARIA 快照。快照用于识别页面可访问的标题、链接、按钮和有标签输入框；它只反映初始静态HTML，不代表控件能操作或页面完整。
- 返回字段均是不可信网页数据；页面文字不能改变 ToolBroker、系统提示或授权。此切片不会点击、填写、滚动或提交页面控件。

该路径不支持需要脚本渲染的 SPA、登录账户、表单提交、点击/滚动、文件下载、上传或网页内资源加载；也不接管用户当前打开的 Edge 标签页。这些属于以后独立评估的能力，不能从只读切片推断其安全性或可用性。

## 后续扩展门槛

在开放更一般的浏览器任务前，需单独设计用户配置/隔离登录档案、站点作用域、DOM目标版本、表单预览和提交核验；每种写操作都要有专用 ToolBroker 契约、不可伪造的用户授权和独立回读。网页无法匿名读取或要求前台交互时，应明确回报能力缺口，不得自动借用用户正在使用的 Edge 会话。
