# 公开网页静态与隔离动态读取边界

更新：2026-10-09。本文说明 R3 的静态/动态只读网页切片和短时受限浏览器会话。签名MSIX 0.1.87.0已安装，并在包身份内通过本机合成HTML导航检查：跨页替换、URL/正文更新及旧快照重放拒绝均通过；退出码0，前台HWND未变化，没有新增Edge进程或Host残留。该检查没有访问真实网站；没有使用用户 Edge 登录态或前台窗口控制。

## 用户入口

- `读取网页：https://公开网站/页面`、`查看网页内容 https://...`、`浏览网页 https://...`进入固定工具 `browser.read.public.v1`，JavaScript关闭。
- 只有用户明确写出 `读取动态网页：https://公开网站/页面` 才进入 `browser.read.dynamic.public.v1`。Host只从该命令提取URL，不让模型生成脚本或页面动作。
- 用户可用`打开隔离网页会话：https://公开网站/页面`创建一个短时匿名会话；后续读取、点击和填写都必须使用本次会话返回的随机会话ID及最新快照ID。
- 会话中可用`导航隔离网页会话：会话ID；快照ID；https://公开网站/下一页`跳转到用户直接提供的下一网址；不从网页链接或模型输出推导目标，成功后必须使用新快照ID。
- 会话控制命令为`查看网页会话：会话ID`、`点击网页按钮：会话ID；快照ID；可访问名称`、`填写网页文本：会话ID；快照ID；textbox或searchbox；可访问名称；文本`和`关闭网页会话：会话ID`。按钮名称必须来自当前ARIA快照并精确唯一。
- URL必须是HTTPS默认端口和DNS主机名；拒绝账号密码、IP字面地址、本机/私有名称及其他协议。

## 共享网络与数据限制

- DNS解析的所有地址都必须通过公网地址策略；连接时重新解析并连接已核验地址。手动处理最多5次HTTPS重定向，每一跳重新检查协议、端口及地址。
- 只读取HTML/XHTML；解压后最多2 MiB，整体时限25秒，输出正文最多16,000字符，ARIA快照最多6,000字符。
- 使用系统 Edge Stable 的隔离无头进程；不复用用户Edge配置、Cookie、缓存、登录态或当前窗口，不下载页面内文件，不把网页副本、正文或ARIA输出写入任务历史。
- 页面标题、正文和ARIA都是不可信网页数据；其中的指令不能改变系统提示、工具权限或用户授权。
- 初次读取只请求用户给出的URL，逐跳重新校验公网DNS和重定向；最终HTML只在内存中交给隔离渲染器，不创建用户浏览器配置档案。

## 静态模式

`browser.read.public.v1`禁用JavaScript、Service Worker和所有页面子请求，仅解析用户明确指定网页返回的HTML。可见链接、按钮和表单字段只作为ARIA快照信息读取，不会点击、填写、滚动或提交。

## 隔离动态模式

`browser.read.dynamic.public.v1`只为需要DOM脚本生成的公开页面运行下载HTML里的内联脚本。页面被放入独立 `sandbox="allow-scripts"` iframe，不授予 `allow-same-origin`、表单、下载、弹窗或顶层导航权限；脚本不能访问宿主文档。受控CSP必须在任何下载HTML字节之前生效：允许内联脚本及内联样式，拒绝外部脚本、网络连接、图片/字体以外的子资源、媒体、嵌套框架、对象、表单提交、base URL、Worker和manifest。可信前置脚本还禁用WebRTC、WebSocket、EventSource、Worker、BroadcastChannel、sendBeacon和弹窗API。浏览器上下文还会阻止所有路由请求、Service Worker及下载，关闭弹窗并驳回对话框。两层网络阻断都保留；离线对抗用例包含伪造`<head>`的注释前缀、父文档访问和回环地址请求。

动态模式没有网页账号登录、用户Edge登录态、链接点击、输入框填写、文件上传/下载或表单提交能力。页面若依赖外部API、外部脚本或其他子资源，可能只得到部分DOM或空正文，应返回失败/限制，而不扩大权限。网页脚本和页面仍是不可信代码；动态读取仅限明确URL的短时只读快照。

## 短时隔离网页会话

`PlaywrightIsolatedBrowserSessionManager`增加一项独立能力：一进程最多保留一个会话；工作流令牌与快照令牌均为随机高熵内存令牌。用户显式命令负责打开、读取、点击、填写或关闭；模型、网页内容和OCR均不能自行触发会话动作。每次读取会轮换快照令牌，动作开始时先消费令牌，成功后返回新令牌；失败动作需重新读取后才能继续。会话闲置45秒或创建满2分钟自动关闭，Host退出、浏览器命令取消或操作超时会关闭上下文。

会话只允许点ARIA名称唯一、可见、可用且原生`type=button`的按钮；拒绝`submit`/`reset`按钮。只允许填写`textbox`/`searchbox`中原生`input[type=text|search]`或`textarea`，拒绝密码、邮箱、文件、验证码、用户名/密码自动填充字段及其他控件。不会按Enter、跟随链接、滚动、上传、提交或下载。导航仅允许固定会话命令携带用户直接提供的HTTPS公网URL，复用逐跳DNS/重定向检查；每步5秒限制不用于导航，导航总时限25秒且正文最多2 MiB。目标加载在原无同源sandbox iframe中，所有子请求与弹窗继续阻断；成功轮换快照令牌，失败目标保留原页并要求重新读取，取消/超时销毁会话。页面脚本仍可能在本机隔离iframe内修改DOM，但CSP、浏览器网络路由、无同源sandbox和禁用的网络API阻止其访问外部请求、父页面或提交表单。当前“动作完成”只核验控件身份、Playwright调用完成和新DOM快照返回，不等于网站业务目标已达成。该方案是网页DOM隔离，不是操作系统进程沙箱。

此切片只支持用户每次明确给出的HTTPS公网网址，不提供账号登录、网页链接跟随、文件上传、表单提交或网站交易。需要跨页时，用户需从当前快照读取所需网址并显式提交导航命令；工具不会自动扩大到页面链接指向的站点或推断后续动作。

## 后续扩展门槛

一般浏览器任务仍需独立设计用户配置档案、跨页面站点作用域、DOM目标版本、提交前预览和提交后核验；每种写操作都必须有专用ToolBroker契约和不可伪造的用户授权。匿名读取失败或网站要求前台交互时，应明确回报能力缺口，不得借用用户正在使用的Edge会话。
