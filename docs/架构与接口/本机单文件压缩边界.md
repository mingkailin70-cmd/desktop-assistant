# 本机单文件压缩边界

## 用户入口

使用“压缩文件：完整本机路径”，例如“压缩文件：D:\\Users\\你\\Documents\\报告.xlsx”。引号可选。命令处理固定为单文件 ZIP，不会依据文件内容选择工具，也不会把模型生成的路径当作目标。

## 固定限制

- 源必须是已配置搜索目录中的本机普通文件，路径必须是完整本机路径；拒绝 UNC、网络盘、备用数据流、重解析点、硬链接、设备和特殊文件。
- 源文件最大 100 MiB。只读取通过 Windows 句柄核验的源文件，不修改或删除它。
- 输出固定写入小K用户数据目录下的 `Exports`，名称为“原文件名.zip”；ZIP 中只有一个以原文件名命名的顶层条目，不保存目录树。
- 已有同名输出一律拒绝，不覆盖。不会接受任意输出路径，不会解压或执行压缩包。
- 写入临时文件后重新读取 ZIP，检查唯一条目、名称、长度和内容 SHA-256；核验通过后以不覆盖方式发布，再比较已发布压缩包与临时包的 SHA-256。
- 用户取消仅在发布前阻止操作。发布后即使取消请求到达，也继续核验；若发布后的文件身份或摘要无法确认，报告“结果待人工核对”，不自动重试。
- 操作在后台运行，不切换窗口、不模拟输入、不借用剪贴板。正常的任务中心状态与结果仍会显示。

## 失败行为

源文件越界、读取失败、大小超限、输出目录失效、同名冲突、内容变化、取消或压缩校验失败时，小K停止并给出具体状态。发布前失败会清理本次临时文件；发布后无法核实时保留输出供用户检查，不重复执行。

## 验收状态

当前源码切片由固定 `file.archive.single.v1` 工具、中文确定性任务路由和 Windows 文件适配器构成。合成安全用例覆盖正常压缩、解压内容与源散列核对、源保持、同名冲突、搜索根外拒绝、任意目标/错误前置条件、超限与预取消。真实用户目录文件、安装版操作、并发替换压力和长期运行尚未验收；源码通过或生成 MSIX 均不代表这些场景已经可用。
