# 本机文件内容搜索边界

## 用户入口与工具契约

用户可用确定性文本命令发起搜索：

- `在文件内容中搜索：关键词`
- `搜索文件内容：关键词`
- `查找文件内容：关键词`
- `在文件中查找：关键词`

Host只将通过本地命令解析的查询提交到固定工具`file.search.content.v1`。ToolBroker校验目标、参数、已配置搜索根前置条件和`MatchingFileContentLocationsListed`预期结果后，调用Windows文件适配器的后台入口。模型不能指定任意扩展名、扫描上限、文件路径或脚本，也不能通过工具输出接续自动动作。

## 读取范围与资源上限

- 只遍历用户明确配置的现存本机目录；拒绝UNC/网络位置和磁盘根路径。
- 最多递归5层、检查5,000个目录项；只读取固定扩展名的文本文件，不读取`.env`、数据库、Office文档或二进制文件。
- 查询最多120个可见字符；单个文件最多2 MiB，一次任务最多读取64 MiB。
- 最多返回10个匹配文件、每个文件最多5个行号。达到数量或读取上限时，摘要提示结果可能不完整。
- 只支持严格识别的UTF-8、UTF-16 LE/BE及其有效BOM；不支持或非法编码会跳过，不以替换字符继续匹配。

搜索适配器通过普通Windows文件句柄检查最终路径、卷与文件ID、链接数和重解析属性。目录联接、符号链接、设备、硬链接、越界最终路径及身份不稳定对象不会被读取。开始读取前后都会核对文件身份、大小与最后写入时间；遇到并发改变、权限问题或格式问题即跳过，并在结果摘要中标示不完整。

## 隐私与前台行为

匹配过程在本机完成，不调用模型、不联网、不操作前台窗口。工具返回只含文件路径、行号及资源统计；匹配行、文件片段和原始查询不写入SQLite、持久任务历史或日志。文本缓冲仅在本次查找的内存比对过程中短时存在。当前任务中心可暂时显示位置结果；进程结束后不保留搜索结果。

## 当前证据与剩余验证

合成检查覆盖：匹配行只返回位置；根外文件、`.env`、二进制、坏编码和超大文件不产生内容泄露；无效查询和取消会失败关闭。源码Release构建及全套Windows安全/桌面体验检查、MSIX签名包、用户目录性能和安装版操作仍以最新[开发进度与待办](../产品与进度/开发进度与待办.md)记录为准。

尚未证明真实用户目录的大规模性能、中文/UTF-16所有编码组合、长时间并发编辑、恶意本机文件系统竞态和桌面安装版可用性。该功能不能替代完整全文索引或Office/PDF内容提取。
