# 公网文件下载边界

状态：源码切片已接入，当前仅有合成响应和本机导出边界检查；真实公网文件、安装版、断网与长期运行测试仍未完成。此功能不读取用户 Edge 登录状态，也不代表能处理需要登录、脚本或表单的下载站点。

## 固定接口

- 工具 ID：`browser.download.public.v1`。
- 用户命令：`下载文件：https://公开网站/文件名`。
- 唯一工具参数：用户本次指令中的 `url`。
- 固定目标：小K数据目录下的 `Exports`；不接受模型或网页指定保存路径。
- 前置条件：`UserProvidedPublicFileUrl | ConfiguredFileExportRoot`。
- 可观察预期：`PublicFileDownloadedToConfiguredExport`。
- 执行入口：`ToolBroker.ExecuteBackgroundAsync`；模型、网页内容不能绕过该入口直接写文件。

## 网络边界

1. 仅接受用户本次任务明确给出的标准 HTTPS 公网 URL，端口固定443；拒绝 HTTP、文件协议、凭证内嵌、IP字面量、内网和本机地址。
2. 每次请求前解析 DNS，返回集合中只要含有非公网地址就拒绝；socket连接时再次核验并连接到解析出的核验地址。关闭自动重定向；每一跳重新核验，最多5次，且只能继续访问 HTTPS 443 公网地址。
3. 不发送 Cookie，不使用系统代理，不读取用户浏览器配置、登录状态或客户端数据。默认 TLS 证书校验保持开启。
4. 总时限45秒；文件解压后上限50 MiB。流式读取超过上限、响应状态失败、超时、取消、DNS错误和网络失败都会停止，不发布部分文件。
5. 不执行脚本，不解析网页，不读取下载内容并交给模型，也不记录响应正文。

## 文件与写入边界

- 拒绝 HTML/XHTML、JavaScript、Windows可执行文件、脚本和快捷方式扩展名或对应危险媒体类型；另以文件头拒绝 PE (`MZ`) 和 shebang 脚本。此规则减少误存活动内容，不是完整反恶意软件扫描。
- 文件名来自 `Content-Disposition`，缺失时取最终 URL 的最后路径段。UTF-8 RFC 5987 名称按框架解析后再校验；路径分隔符、非法字符、保留设备名、尾随点/空格、危险扩展名和过长文件名均拒绝。
- 仅保存到固定 `Exports`。不覆盖同名目标；写入随机临时文件，核对导出目录仍是原目录后用同卷不替换式改名发布。发布后重新打开并核对路径、大小和 SHA-256。
- 取消只在发布前阻止写入。发布后总是完成核验；若结果无法独立确认，标为 `OutcomeUncertain`，要求人工检查，不能自动重试。
- 下载字节只短暂保存在内存并写入用户请求的导出文件；不放入SQLite任务记录、仓库或模型请求。

## 当前验证范围

合成检查覆盖HTTPS公网URL策略、危险扩展名/媒体类型/文件头、RFC 5987 Unicode与路径穿越文件名、ToolBroker参数/目标/前置条件/预期结果、固定导出目录、成功写入、SHA-256、同名冲突、网络失败和预取消。它没有实际连接公网下载文件，也没有覆盖全部服务器实现、代理环境、内容编码组合、安装版UI或用户工作负载期间的完整前台句柄观测。发布前仍需进行受控公网下载和安装版正常/失败/取消验收。
