# 本机文件分类边界

## 用法与结果

用户可输入“分类文件夹：本机完整目录路径”“查看文件分类：本机完整目录路径”或“预览文件分类：本机完整目录路径”。该操作由确定性路由直接进入固定工具，不调用模型，也不要求切换到资源管理器。

小K只根据普通文件的扩展名将其计入文档、图片、视频、音频、压缩包、安装程序、代码与配置、其他八类。结果给出各类数量和少量相对路径示例；不打开文件，不读取正文、媒体元数据或压缩目录，也不复制、移动、重命名或删除文件。此分类是帮助定位内容的粗略索引，不证明文件真实格式或安全性。

## 范围与上限

- 起始目录必须是本机盘符路径，并位于设置中已有的文件搜索根内；拒绝 UNC、备用数据流、设备路径和链接目录。
- 递归最多五层，最多检查5,000个目录项。遇到访问失败、身份变化、重解析点、深度上限或数量上限时，结果会标示扫描可能不完整。
- 子目录和文件都通过 Windows 目录句柄核对文件身份及最终路径；拒绝重解析点，且每项都再次验证位于起始目录和配置搜索根内。
- 完整路径不会被保存到任务数据库。分类报告只作为当前任务的短期结果显示；用户可取消扫描，预取消不启动目录枚举。

此功能只解决只读“看有哪些类型”问题，不会按分类创建文件夹或整理文件。任何后续复制、移动或重命名都必须使用各自的固定工具、限定目录、明确结果核验和对应授权流程。

## 验收状态

合成夹具验证扩展名大小写映射、嵌套目录、未知扩展名、搜索根外拒绝、目录联接不跟随、错误 ToolBroker 目标/前置条件、预取消，以及源内容和目录文件集合在扫描前后保持不变。该检查不代表对用户文件的扫描实测，也不代表后续文件整理已实现。
