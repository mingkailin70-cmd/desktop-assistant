# 本机目录压缩边界

更新：2026-10-09。本切片增加目录 ZIP 压缩；原来的“压缩文件”单文件命令与工具保持不变。

## 用户入口

使用“压缩文件夹：完整本机目录路径”，例如“压缩文件夹：D:/Users/你/Documents/项目资料”。只从用户明确给出的路径读取，不让模型指定导出位置或生成脚本。

## 固定范围

- 目录必须是设置中已配置搜索根内的本机普通目录；拒绝卷根、UNC/网络路径、重解析点、链接和特殊目录。
- 扫描最多递归5层、5,000个目录项、1,000个普通文件。每个文件最多100 MiB，合计最多500 MiB，生成的 ZIP 最多540 MiB。触及任一上限即停止，不发布不完整归档。
- 普通文件的相对目录结构保留在 ZIP 中，并以所选目录名作为顶层目录。空目录不单独写入归档；不读取搜索根外的目标。
- 不接受搜索根外路径、硬链接文件、设备项、符号链接、目录联接或其他重解析点。源目录与用户数据目录下的 Exports 重叠时拒绝，以免把已有导出文件打包回去。
- 输出固定写入用户数据目录下的 Exports 子目录，并以目录名加 .zip 命名。同名文件一律拒绝覆盖，不接受任意输出路径。

## 变更检测与核验

压缩前先枚举并记录每个普通文件的稳定身份、长度、修改时间和相对路径；压缩时重新打开并核对文件身份，逐块计算 SHA-256。目录结构、文件身份或元数据变化时停止。ZIP 暂存文件重新打开后，会检查条目数、每个路径与长度，并逐项解压计算内容 SHA-256；之后再扫描一次源目录比较清单和目录身份。全部通过后才以不覆盖方式发布 ZIP，并核对发布文件散列。原目录和源文件不会被修改。

任务取消在 ZIP 发布前生效并清理本次临时文件。发布完成后继续做核验；无法确认的结果会提示人工检查导出目录，不会自动重试。

## 当前证据与未覆盖项

Release 合成检查覆盖嵌套目录及 Unicode 文件名、ZIP 内容与路径、源数据保持、同名冲突、搜索根外拒绝、目录联接拒绝、递归深度上限、固定 ToolBroker 参数和预取消；完整解决方案构建通过。检查只使用临时合成文件。真实用户目录、接近体积上限的大型目录、源文件并发修改压力、安装版与长时间运行仍待验收。

该工具只压缩本机目录，不会解压或执行归档。它不能替代杀毒检查；压缩包内文件保持用户原有内容和风险属性。
