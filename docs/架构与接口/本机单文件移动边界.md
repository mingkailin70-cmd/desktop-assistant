# 本机单文件移动边界

## 功能范围

固定命令为“移动文件：完整源文件路径 到 目标目录完整路径”。小K每次只移动一个文件，保留原文件名；源文件和目标目录都必须位于设置中配置的本机搜索范围，并在同一卷。适配器不创建目标目录，不批量整理，不跨卷复制，也不覆盖同名文件。

该功能作为后台工具运行，不启动应用、不切换窗口、不模拟鼠标键盘、不访问剪贴板。它不读取文件内容，只核对 Windows 返回的路径、文件身份、大小和修改时间。

## 目标与路径核验

ToolBroker 只接受 `file.move.v1`、两个固定参数 `source_path` 与 `destination_directory`、固定目标 `configured-search-roots`，以及 `ConfiguredSearchRoot | ConfiguredMoveDestination` 和 `FileMovedWithinConfiguredSearchRoots`。自然语言入口使用确定性解析，不让模型把任意路径、脚本或点击坐标变成动作。

源必须是本机普通单文件，重解析点、设备、硬链接、UNC、备用数据流及搜索根外路径均拒绝。目标必须是已存在且可写的本机普通目录，并通过不跟随重解析点的句柄取得最终路径和文件身份；目录联接或越界目标拒绝。源文件及其父目录同样取得稳定句柄并核对搜索根。文件与目标目录的卷序列号必须相同，目标不能等于当前父目录。

## 原子提交与核验

执行前检查目标同名项不存在、源文件和两个目录仍指向已核验身份，并再次检查取消。随后持有源文件、源父目录和目标目录句柄；源文件句柄不共享写入或删除权限，目录句柄不共享删除权限，避免执行期间改写源文件或替换已核验路径。适配器以不允许替换目标的 `SetFileInformationByHandle(FileRenameInfo)` 在同卷原子移动单个文件，使用 Windows 规范化的完整目标路径和空 `RootDirectory`。

提交前取消不会移动文件。如果提交请求已经发出，适配器即使收到取消也先完成核验，不会重试：重新打开目标并核对路径、卷/文件ID、大小和修改时间，确认旧路径不存在。全部条件成立才报告成功；无法确定最终状态时返回 `outcome_uncertain` 并提示人工核对，不自动再移动一次。执行中出现目标冲突时 Windows 的不替换语义会拒绝覆盖，并保留源文件。

## 验收范围

合成检查覆盖固定语法、后台准入、成功移动及字节内容保持、同名冲突、搜索范围外源与目标、任意目标/错误前置条件、同目录目标、预取消及源/目标目录联接。检查只使用临时合成文件，没有整理用户目录，也不代表当前安装版已经具备该功能。

批量按类型整理、不同卷复制、自动创建目录、用户正在使用的文件占用处理策略以及实机并行竞态压力测试仍未完成。
