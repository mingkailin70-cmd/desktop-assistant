# 小K用户指南（开发阶段）

> 当前状态：早期工程切片。WPF桌面壳、有限本地工具、Windows 通知监听接入和隔离编程补丁生成链路可编译；本地模型、语音、MSIX授权运行、浏览器操作和微信/QQ发送尚未完成验收。此文不是已发布产品的安装承诺。

## 现在可用的开发切片

开发机需要 Windows 和 .NET SDK 10.0.401。本地命令如下：

    .\.tools\dotnet\dotnet.exe --version
    .\.tools\dotnet\dotnet.exe build XiaoK.sln --configuration Release --no-restore
    .\.tools\dotnet\dotnet.exe run --project tests\XiaoK.Tools.SafetyChecks\XiaoK.Tools.SafetyChecks.csproj --configuration Release --no-build --no-restore
    .\.tools\dotnet\dotnet.exe run --project src\XiaoK.Host\XiaoK.Host.csproj --configuration Release --no-build --no-restore

桌宠当前提供文本框、Ctrl+Shift+K、托盘、取消与停麦入口。**取消任务**会停止当前任务并同时发出停麦信号；**停麦**只停止麦克风采集，不会取消桌面任务。当前语音运行时尚未接入，因此停麦操作会明确显示麦克风当前未采集。通过托盘选择退出时，小K会先请求取消当前任务，等待任务完成本地状态处理后再关闭；退出不会自动重放外部动作。设置页可配置仓库外的数据目录、模型目录、评测目录和仅限回环地址的本地推理端点；保存后重启生效。未打包开发版可以选择在当前用户登录后于托盘启动。MSIX 版的 StartupTask 仍待接入。设置页可按需读取小K进程 CPU/RAM、NVIDIA 显卡系统总显存及 DXGI 统计的当前 Host 进程本地显存；该进程读数不含独立启动的模型或语音服务，且需结合本机实测判断。评测目录清理会显示目标与文件数并再次确认，只处理目录顶层普通文件。当前文件搜索仅走已配置的本机盘符目录，拒绝 UNC 网络路径和磁盘根目录；目录项从已打开的 Windows 目录句柄枚举，子目录与匹配文件再按卷序列号、128位文件 ID 和最终路径核验，不跟随重解析点。对抗性并发替换压力测试尚未完成。允许列表中的应用启动和有限范围文件名查找已有骨架。本地推理客户端只接受回环地址；本机模型服务器未启动时会明确提示，不调用云端服务。

点击桌面窗口的“记录”按钮，或在托盘菜单选择“最近任务”，可查看最近任务的类别、状态、更新时间和隔离编程工作区路径。列表不展示任务请求正文、通知内容或模型回答；路径可复制后由用户自行检查。该页面只帮助定位保留的工作区，不会续跑、重放步骤、合并补丁或删除任务。程序意外退出时，最近持久化状态可能仍显示“规划中”或“运行中”；真实模型任务的崩溃恢复尚未验收。

## 首版计划中的用法

- 打开应用：“打开小K项目”或“打开 Edge”。
- 找文件：“查找文件 预算”。
- 编程任务：在设置中选择项目和仓库外的隔离工作区，保存后重启小K；本地模型最多选4个文本文件生成补丁。审阅窗会显示完整差异；默认仅保留补丁。唯一 .NET 解决方案/项目可选择单独批准依赖还原与测试。还原仅使用 nuget.org、包缓存位于隔离任务目录；构建目标和测试代码仍可能联网或写入其他位置，只对你信任的项目批准。小K不自动合并回原项目；真实凭证不要放在所选项目的源码中。详细范围见[隔离编程代理与工作区](../架构与接口/隔离编程代理与工作区.md)。
- 理解聊天：当前可在输入框粘贴单条消息并输入“分析消息：内容”；Windows 通知策略已接入，但私聊分类和 MSIX 授权尚未验收，因此现在不会从通知正文自动分析。
- 起草回复：不指定联系人时输入“帮我回复：对方消息”，使用简洁风格。先在设置的“联系人回复风格”中保存联系人名称和固定风格后，可输入“帮我回复给联系人名：对方消息”；没有匹配到已保存偏好时小K会停止并提示设置，不会猜联系人。风格可选择简洁、正式、友好、轻松或共情，可在设置中更新或删除。联系人名称只用于本机查找偏好，不发送给模型；消息正文仍仅发往本机模型，结果只是草稿，不会自动发送。
- 发送：当前没有微信/QQ发送适配器；小K不会外发消息。首版设计要求未来展示最终收件人、完整正文和附件并等待确认。

微信/QQ通知访问需要具有包身份的 MSIX 并取得 Windows 授权。当前发布者 AUMID 和私聊/群聊格式尚未用真实客户端通知核实；会话归属不明时策略不会读取正文。最终启用时，无正文只提醒你手动打开会话；小K不会抢焦点、读取客户端数据库或注入进程。

## 数据与隐私

模型和推理链路只允许本机回环端点，不会把请求回退到云端。托管 llama.cpp 生命周期代码已加入，但本机没有已验收的运行包或模型权重。模型目录没有 `llama-runtime.json` 时，小K只连接设置页中的手动本机服务；存在清单时会先核对固定版本与运行时/权重 SHA-256，通过后才启动，空闲4分钟停止。无效清单会阻止模型请求。通知原文、截图和录音默认不写入持久化存储。联系人回复风格只保存在当前用户的本地设置中，记录联系人名称、固定风格、用户确认来源和更新时间，设置页提供删除入口；聊天正文和模型草稿不随偏好保存。用户同意保存的脱敏评测样本单独放在仓库外，并可删除。开发版任务记录不保存原始请求或模型回答。

规划中的默认数据目录为 D:\XiaoK\Data、模型目录 D:\XiaoK\Models、缓存 D:\XiaoK\Cache、评测目录 D:\XiaoK\Evaluations；实际路径需可配置。仓库设置样例见[settings.example.json](../../src/XiaoK.Host/settings.example.json)，应用设置位置为 `%LOCALAPPDATA%\XiaoK\settings.json`。

## 尚未交付的能力

CPU唤醒词、VAD、ASR/TTS、模型权重和 llama.cpp 运行包部署、GPU 预算本机校准、Edge自动化、SQLite存储、MSIX签名/安装、MSIX 登录启动集成、自动更新与回滚都还没有完成。托管模型进程生命周期和显存准入代码已有，但尚未用实际版本/权重验证启动、哈希拒绝、空闲卸载、1 GiB 余量与退出回收。Windows 通知监听尚未在有效 MSIX 身份下运行验收；隔离代码补丁链路的本机模型、端到端崩溃恢复、凭证检测、命令审批和成功率均未验收。最近任务页面仅展示安全筛选后的已有状态和工作区路径，不会自动恢复运行中任务。登录启动选项尚未做锁屏、重启和长期运行验收。P0/P4门槛未通过前，请不要把开发切片用于无人值守消息处理或自动发送。
