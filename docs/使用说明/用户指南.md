# 小K用户指南（开发阶段）

> 当前状态：早期工程切片。WPF桌面壳、有限本地工具、Windows 通知监听接入和隔离编程补丁生成链路可编译；本地模型、语音、MSIX授权运行、浏览器操作和微信/QQ发送尚未完成验收。此文不是已发布产品的安装承诺。

## 现在可用的开发切片

开发机需要 Windows 和 .NET SDK 10.0.401。本地命令如下：

    .\.tools\dotnet\dotnet.exe --version
    .\.tools\dotnet\dotnet.exe build XiaoK.sln --configuration Release --no-restore
    .\.tools\dotnet\dotnet.exe run --project tests\XiaoK.Tools.SafetyChecks\XiaoK.Tools.SafetyChecks.csproj --configuration Release --no-build --no-restore
    .\.tools\dotnet\dotnet.exe run --project src\XiaoK.Host\XiaoK.Host.csproj --configuration Release --no-build --no-restore

只检查窗口外观时，可用隔离诊断配置启动，不会读取常规设置或打开 `D:\XiaoK\Data`：

    .\.tools\dotnet\dotnet.exe .\src\XiaoK.Host\bin\Release\net10.0-windows10.0.26100.0\XiaoK.Host.dll --diagnostics-profile

该模式会把临时设置、任务数据库和隔离目录写入 `%TEMP%\XiaoK-Diagnostics-<随机ID>`；微信/QQ通知、模型推理、桌面工具与语音采集均关闭。提交任务只显示未执行提示。退出后临时目录保留，便于检查。

桌宠当前提供文本框、Ctrl+Shift+K、托盘、取消与停麦入口。展开面板中的“查找文件”“解释代码”“分析消息”“起草回复”快捷按钮会填入对应命令前缀；补充关键词或单条消息后再按“运行任务”。“解释代码：问题”会在设置中选择的项目快照里检索并返回本地说明，不改原项目、不生成补丁或运行命令；该路径已有合成安全检查，尚未接入已验收的模型权重。编程修改任务仍通过“编程任务”说明启动，审阅窗展示差异。“打开 VS Code 项目”直接调用现有应用启动流程。“切换到 Edge”“切换到微信”或“切换到 VS Code 小K项目”会尝试切换到已打开且属于允许列表的窗口；目标最小化时会恢复窗口，随后核对它是否真的处于前台。目标不存在时不会启动应用。该功能刚完成代码实现，尚未进行小K窗口切换实测。**取消任务**会停止当前任务并同时发出停麦信号；**停麦**只停止麦克风采集，不会取消桌面任务。当前语音运行时尚未接入，因此停麦操作会明确显示麦克风当前未采集。分析和起草需要可用的本地推理端点；未连接时只提示本地服务不可用，不转发到云端。通过托盘选择退出时，小K会先请求取消当前任务，等待任务完成本地状态处理后再关闭；退出不会自动重放外部动作。设置页可配置用户数据、模型、评测目录、文件搜索目录、VS Code/Edge/微信/QQ本机程序和小K项目目录，以及仅限回环地址的本地推理端点。新建开发设置时，主模型根目录默认是仓库内被 Git 忽略的 `models/llm/qwen3.5-4b/<固定revision>/`；ASR/TTS 权重位于 `models/speech/` 下各自的模型版本目录。数据库、缓存和评测目录仍默认位于仓库外。搜索目录每行一个，最多20个，必须是已存在的本机目录，拒绝 UNC 和映射网络盘、盘符根目录；应用程序按固定可执行文件名校验。保存路径后重启生效。未打包开发版可以选择在当前用户登录后于托盘启动；MSIX StartupTask 状态与请求 API 已接入，签名安装、系统授权和登录恢复行为仍待实机验收。设置页可按需读取小K进程 CPU/RAM、NVIDIA 显卡系统总显存及 DXGI 统计的当前 Host 进程本地显存；该进程读数不含独立模型或语音服务进程，且需结合本机实测判断。评测目录清理会显示目标与文件数并再次确认，只处理目录顶层普通文件。文件搜索只遍历已配置的本机目录；目录项从已打开的 Windows 目录句柄枚举，子目录与匹配文件再按卷序列号、128位文件 ID 和最终路径核验，不跟随重解析点。对抗性并发替换压力测试尚未完成。允许列表中的应用启动和有限范围文件名查找已有骨架。本地推理客户端只接受回环地址；本机模型服务器未启动时会明确提示，不调用云端服务。

点击桌面窗口的“记录”按钮，或在托盘菜单选择“最近任务”，可查看最近任务的类别、状态、更新时间和隔离编程工作区路径。列表不展示任务请求正文、通知内容或模型回答；路径可复制后由用户自行检查。该页面只帮助定位保留的工作区，不会续跑、重放步骤、合并补丁或删除任务。程序意外退出时，最近持久化状态可能仍显示“规划中”或“运行中”；真实模型任务的崩溃恢复尚未验收。

## 首版计划中的用法

- 打开应用：“打开小K项目”或“打开 Edge”。
- 切换窗口：“切换到微信”或“切换到 Edge”；只切换到已打开且符合本机白名单的窗口，不存在时不会启动应用。VS Code 项目以配置目录名匹配窗口标题。
- 找文件：“查找文件 预算”。
- 只读代码检索：“解释代码：说明启动时如何加载配置”。
- 编程任务：在设置中选择项目和仓库外的隔离工作区，保存后重启小K；本地模型最多选4个文本文件生成补丁。审阅窗显示完整差异，并提供“保留补丁”“批准还原依赖并运行测试”和“批准应用补丁”三种选择。只有明确批准应用后，才会重新核对原文件与审阅补丁；任一目标文件变化时整批停止。替换失败会尝试恢复已写文件，无法确认时保留事务日志并提示人工核对，不会自动重试。依赖还原仅使用 nuget.org、包缓存位于隔离任务目录；构建目标和测试代码仍可能联网或写入其他位置，只对你信任的项目批准。真实凭证不要放在所选项目的源码中。详细范围见[隔离编程代理与工作区](../架构与接口/隔离编程代理与工作区.md)。
- 理解聊天：当前可在输入框粘贴单条消息并输入“分析消息：内容”；Windows 通知策略已接入，但私聊分类和 MSIX 授权尚未验收，因此现在不会从通知正文自动分析。
- 起草回复：不指定联系人时输入“帮我回复：对方消息”，使用简洁风格。先在设置的“联系人回复风格”中保存联系人名称和固定风格后，可输入“帮我回复给联系人名：对方消息”；没有匹配到已保存偏好时小K会停止并提示设置，不会猜联系人。风格可选择简洁、正式、友好、轻松或共情，可在设置中更新或删除。联系人名称只用于本机查找偏好，不发送给模型；消息正文仍仅发往本机模型，结果只是草稿，不会自动发送。
- 发送预览：输入“发送微信给张三：正文”或“发送QQ给张三：正文”，小K会显示应用、最终收件人和完整正文。此版本只做无附件预览，关闭预览即结束；微信/QQ发送适配器尚未接入，不会外发，也不会记成已批准。带有“；附件：”或“;附件:”的请求会明确拒绝。

微信/QQ通知访问需要具有包身份的 MSIX 并取得 Windows 授权。当前发布者 AUMID 和私聊/群聊格式尚未用真实客户端通知核实；会话归属不明时策略不会读取正文。最终启用时，无正文只提醒你手动打开会话；小K不会抢焦点、读取客户端数据库或注入进程。

## 数据与隐私

模型和推理链路只允许本机回环端点，不会把请求回退到云端。托管 llama.cpp 生命周期代码已加入，但本机没有已验收的运行包或模型权重。模型目录没有 `llama-runtime.json` 时，小K只连接设置页中的手动本机服务；存在清单时会先核对固定版本与运行时/权重 SHA-256，通过后才启动，空闲4分钟停止。无效清单会阻止模型请求。通知原文、截图和录音默认不写入持久化存储。联系人回复风格保存在本机 SQLite，记录联系人名称、固定风格、用户确认来源和更新时间，设置页提供更新和删除入口；偏好迁移不改写旧 `settings.json`，新界面不再把新偏好写回该文件。聊天正文和模型草稿不随偏好保存。用户同意保存的脱敏评测样本单独放在仓库外，并可删除。开发版任务记录不保存原始请求或模型回答。

设置页的“本地存储”区域可创建 SQLite v4 数据库备份、从兼容备份恢复，并查看最近100条只读审批记录。恢复必须先选择备份并确认；小K会检查数据库版本、完整性和表结构，再为当前数据库创建旁置保护副本。恢复只覆盖任务状态、联系人回复风格偏好与有限审批审计，不会恢复或重放运行中的任务、命令或外发操作。可选择 `.sqlite3` 备份或恢复前生成的 `.bak` 保护副本；较旧架构的迁移备份不受此恢复入口支持。备份和恢复路径由用户选择，建议放在仓库外的本机磁盘并妥善保护。当前流程仅通过合成数据库验证，真实数据恢复仍未验收。

同一区域的“清理本地历史数据”会先列出数据库记录数、旧联系人偏好数和可识别的小K旧文件数量，再等待二次确认。确认后会清空 SQLite 中的任务、联系人偏好和审批记录，并保留迁移标记，防止旧源重新导入；还会移除当前 `settings.json` 中仅用于旧迁移的联系人偏好字段，并删除当前数据目录内的旧 `tasks.json`、小K生成的迁移/恢复备份、默认命名备份和恢复暂存文件。无关设置、隔离编程工作区、评测样本、链接/只读文件不在清理范围内。用户另存到其他目录或使用自定义文件名的备份不会自动删除。清理和恢复尚未用真实用户数据演练；操作不保证擦除文件系统快照、SSD磨损均衡副本或其他系统备份。

规划中的默认数据目录为 D:\XiaoK\Data、模型目录 D:\XiaoK\Models、缓存 D:\XiaoK\Cache、评测目录 D:\XiaoK\Evaluations；实际路径需可配置。仓库设置样例见[settings.example.json](../../src/XiaoK.Host/settings.example.json)，应用设置位置为 `%LOCALAPPDATA%\XiaoK\settings.json`。

## 尚未交付的能力

CPU唤醒词、VAD、ASR/TTS、模型权重和 llama.cpp 运行包部署、GPU 预算本机校准、Edge自动化、MSIX签名/安装、自动更新与回滚都还没有完成。SQLite任务状态、联系人偏好、审批审计、备份/恢复和本地历史清理已接入并通过合成数据检查；尚未读取或迁移真实用户数据，也未完成实际恢复/清理演练。托管模型进程生命周期和显存准入代码已有，但尚未用实际版本/权重验证启动、哈希拒绝、空闲卸载、1 GiB 余量与退出回收。Windows 通知监听尚未在有效 MSIX 身份下运行验收；只读代码检索和隔离补丁路径已通过合成安全检查，但真实模型、端到端崩溃恢复、凭证检测、命令审批和成功率均未验收。最近任务页面仅展示安全筛选后的已有状态和工作区路径，不会自动恢复运行中任务。登录启动 API 已接入，但尚未做签名安装后的锁屏、重启和长期运行验收。P0/P4门槛未通过前，请不要把开发切片用于无人值守消息处理或自动发送。
