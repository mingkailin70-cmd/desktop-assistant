“分类文件夹：完整本机目录路径”会按文件扩展名只读统计文档、图片、视频、音频、压缩包、安装程序、代码与配置和其他文件；例如“分类文件夹：D:\Users\你\Downloads”。只检查设置中的搜索目录，最多递归5层/5,000个目录项，最多展示每类两个相对路径示例。不读取文件内容、不修改任何文件、不启动模型、不切换前台。扫描遇到链接、权限或数量限制时会提示结果可能不完整；扩展名分类不证明文件实际格式。

## 本机唤醒词（原型）

唤醒词默认关闭。要试用时，打开“设置 → 登录与能力状态”，勾选“启用本机唤醒词”并保存。只有以已安装 MSIX 身份运行、Windows 提供 `zh-CN` 本地语法且麦克风权限可用时才会启动；普通开发目录会显示原因并保持停麦。开启后支持固定短语“嗨小K”“你好小K”或“Hi 小K”。命中后小K只展开面板并停止监听；你还要点击“开始说话”，检查转写内容，再手动点击“运行任务”。启用选项会随设置保存并在小K下次启动时恢复。锁屏和按键录音期间自动暂停；托盘“停麦”会关闭唤醒开关并保存为关闭。该原型尚未在实际麦克风、语言包和电源状态下验收；低功耗、常驻资源和误唤醒率尚无实测。

## 首版计划中的用法

- 压缩文件夹：“压缩文件夹：D:/Users/你/Documents/项目资料”。只接受设置搜索目录中的本机普通文件夹；ZIP 保留相对目录结构并写到用户数据目录的 Exports 子目录，原目录保留，同名文件不覆盖。最多5层、5,000个目录项、1,000个文件、每个100 MiB、总计500 MiB；链接、特殊项或触及上限时停止，不发布不完整压缩包。详情见[本机目录压缩边界](../架构与接口/本机目录压缩边界.md)。

- 打开应用：“打开小K项目”或“打开 Edge”。
- 切换窗口：“切换到微信”或“切换到 Edge”；只切换到已打开且符合本机白名单的窗口，不存在时不会启动应用。VS Code 项目以配置目录名匹配窗口标题。
- 找文件：“查找文件 预算”。
- 复制单个文件：“复制文件：D:\Users\你\Documents\预算.xlsx”。只接受设置中的搜索目录，复制到 `<用户数据目录>\Exports`；同名文件不覆盖，单文件上限100 MiB。
- 压缩单个文件：“压缩文件：D:\Users\你\Documents\预算.xlsx”。只接受设置中的搜索目录，压缩包写到 `<用户数据目录>\Exports`；原文件保留、同名文件不覆盖，单文件上限100 MiB。
- 重命名单个文件：“重命名文件：D:\Users\你\Documents\预算.xlsx 为 预算-归档.xlsx”。只接受设置中的搜索目录，在原目录内更名且不覆盖目标。
- 移动单个文件：“移动文件：D:\Users\你\Downloads\预算.xlsx 到 D:\Users\你\Documents”。源文件和目标目录都必须在设置中的搜索范围内并位于同一卷；目标重名时拒绝，不创建目录、不覆盖文件，也不会切换前台。
- 移入回收站：“移入回收站：D:\Users\你\Documents\草稿.txt”。只允许搜索根中的单个普通文件，并在任务中心展示规范路径等待逐项确认；链接、越界路径和目标变化时停止。失败或结果不确定时不自动重试。
- 只读分类文件夹：“分类文件夹：D:\Users\你\Downloads”。结果依据扩展名统计，不移动或复制文件。
- 只读代码检索：“解释代码：说明启动时如何加载配置”。
- 编程任务：在设置中选择项目和仓库外的隔离工作区，保存后重启小K；本地模型最多选4个文本文件生成补丁。审阅窗显示完整差异，并提供“保留补丁”“批准还原依赖并运行测试”和“批准应用补丁”三种选择。只有明确批准应用后，才会重新核对原文件与审阅补丁；任一目标文件变化时整批停止。替换失败会尝试恢复已写文件，无法确认时保留事务日志并提示人工核对，不会自动重试。依赖还原仅使用 nuget.org、包缓存位于隔离任务目录；构建目标和测试代码仍可能联网或写入其他位置，只对你信任的项目批准。真实凭证不要放在所选项目的源码中。详细范围见[隔离编程代理与工作区](../架构与接口/隔离编程代理与工作区.md)。
- 理解聊天：当前可在输入框粘贴单条消息并输入“分析消息：内容”；Windows 通知策略已接入，但私聊分类和 MSIX 授权尚未验收，因此现在不会从通知正文自动分析。
- 起草回复：不指定联系人时输入“帮我回复：对方消息”，使用简洁风格。先在设置的“联系人回复风格”中保存联系人名称和固定风格后，可输入“帮我回复给联系人名：对方消息”；没有匹配到已保存偏好时小K会停止并提示设置，不会猜联系人。风格可选择简洁、正式、友好、轻松或共情，可在设置中更新或删除。联系人名称只用于本机查找偏好，不发送给模型；消息正文仍仅发往本机模型，结果只是草稿，不会自动发送。
- 发送预览：按你的限定，QQ 只允许联系人显示名 `K`，微信只允许联系人显示名 `L`。分别输入“发送QQ给 K：正文”或“发送微信给 L：正文”，小K才会显示应用、收件人显示名和完整正文；其他联系人、跨平台名称或大小写不同的名称都会在预览前拒绝。预览窗同时标明客户端账号身份尚未核验。该白名单不是自动发送授权；禁止小K自行或随机发消息。此版本只做无附件预览，关闭预览即结束；微信/QQ发送适配器尚未接入，不会外发，也不会记成已批准。截图中的显示名尚未绑定稳定账号身份，因此后续接入实际发送前还要核实这两个联系人的客户端身份，并且每条消息仍需你确认最终平台、联系人和正文。带有“；附件：”或“;附件:”的请求会明确拒绝。

微信/QQ通知访问需要具有包身份的 MSIX 并取得 Windows 授权。签名 MSIX 已在隔离诊断模式启动并关闭；该模式关闭通知监控，不请求系统授权。当前通知来源 AUMID 和私聊/群聊格式尚未用真实客户端通知核实。设置支持经典桌面应用的非包 AUMID，但只应填写从真实 Windows 通知元数据核对出的完整值；会话归属不明时策略不会读取正文。最终启用时，无正文只提醒你手动打开会话；小K不会抢焦点、读取客户端数据库或注入进程。

## 数据与隐私

模型和推理链路只允许本机回环端点，不会把请求回退到云端。托管 llama.cpp 生命周期代码已加入，Qwen 权重与 b11259 CUDA 13.4 运行资产已校验。独立 llama-bench 确认 GPU 配置卸载33/33层，采样显存占用峰值4,378 MiB、最低空闲3,522 MiB；另有一次 ModelBroker 托管复验记录首请求冷启动6.28秒、10次热请求 p50/p95 为2.82/3.51秒、取消约0.51秒、空闲262秒后卸载及重载、退出后进程回收，运行峰值显存占用4,678 MiB。以上是单轮受控测量，不代表长期稳定、压力/OOM恢复或回答质量验收。模型目录没有 `llama-runtime.json` 时，小K只连接设置页中的手动本机服务；存在清单时会先核对固定版本与运行时/权重 SHA-256，通过后才启动，空闲4分钟停止。无效清单会阻止模型请求。通知原文、截图和录音默认不写入持久化存储。联系人回复风格保存在本机 SQLite，记录联系人名称、固定风格、用户确认来源和更新时间，设置页提供更新和删除入口；偏好迁移不改写旧 `settings.json`，新界面不再把新偏好写回该文件。聊天正文和模型草稿不随偏好保存。用户同意保存的脱敏评测样本单独放在仓库外，并可删除。开发版任务记录不保存原始请求或模型回答。

设置页的“本地存储”区域可创建 SQLite v6 数据库备份、从兼容备份恢复，并查看最近100条只读审批记录。恢复必须先选择备份并确认；小K会检查数据库版本、完整性和表结构，再为当前数据库创建旁置保护副本。恢复只覆盖脱敏任务状态、联系人回复风格偏好与有限审批审计，不会恢复或重放运行中的任务、命令或外发操作。可选择 `.sqlite3` 备份或恢复前生成的 `.bak` 保护副本；较旧架构的迁移备份不受此恢复入口支持。备份和恢复路径由用户选择，建议放在仓库外的本机磁盘并妥善保护。当前流程仅通过合成数据库验证，真实数据恢复仍未验收。

同一区域的“清理本地历史数据”会先列出数据库记录数、旧联系人偏好与桌宠坐标字段数，以及可识别的小K文件数量，再等待二次确认。确认后会清空 SQLite 中的任务、联系人偏好和审批记录，并保留迁移标记，防止旧源重新导入；还会移除当前 `settings.json` 中仅用于旧迁移的联系人偏好和桌宠坐标字段，并删除当前数据目录内精确命名的 `pet-window-position.json`、旧 `tasks.json`、小K生成的迁移/恢复备份、默认命名备份和恢复暂存文件。无关设置、相似名称文件、隔离编程工作区、评测样本、链接/只读文件不在清理范围内。用户另存到其他目录或使用自定义文件名的备份不会自动删除。合成数据回归已通过；清理和恢复尚未用真实用户数据演练。

规划中的默认数据目录为 D:\XiaoK\Data、模型目录 D:\XiaoK\Models、缓存 D:\XiaoK\Cache、评测目录 D:\XiaoK\Evaluations；实际路径需可配置。仓库设置样例见[settings.example.json](../../src/XiaoK.Host/settings.example.json)，应用设置位置为 `%LOCALAPPDATA%\XiaoK\settings.json`。
