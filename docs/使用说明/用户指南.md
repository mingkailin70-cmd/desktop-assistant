# 小K用户指南（开发阶段）

## 调整大小与后台行为（2026-10-08）

拖动桌宠右下角小手柄可调整大小；鼠标放到桌宠上按Ctrl并滚轮，每次改变5%；右键 → 桌宠大小可用40%–160%滑块，托盘也有常用比例。推荐70%，任务面板保持独立大小。位置和比例会保存，旧的仅坐标配置先保留100%。启动/显示桌宠不主动激活窗口，点击任务面板才展开。

后台任务只调用已登记为后台的工具，需前台时反馈且不执行。当前微信/QQ仍只有发送预览，真实后台发送未接入；未来精确普通发送指令可单次授权，草稿、附件或敏感内容仍核对。普通电脑任务按适配器逐项增加，钱包/资金/密码不属于概括授权。详见[最新执行方案](../架构与接口/桌宠复用与不打扰执行方案.md)。下方0.1.40.0描述保留作历史，新版安装证据以进度为准。

> 当前状态：早期工程切片。WPF桌面壳、有限本地工具、Windows 通知监听接入、默认关闭的 Windows 本地唤醒词原型和隔离编程补丁生成链路可编译；首版六类场景、模型质量、语音设备、通知归属、浏览器操作和微信/QQ发送尚未完成验收。源码与当前账户签名 MSIX `0.1.40.0` 中的桌宠、面板头像和欢迎区已统一使用 v15 三维银渐层猫咪素材；该包以诊断模式启动，未加载模型、启用通知监听或麦克风。原生窗口截图与透明合成效果尚未目视验收。主模型/llama.cpp和ASR/TTS环境已部署到D盘正式路径；安装Host重启后显示托管模型按需启动状态，但本轮未加载权重或发起模型请求。通知监听仍默认关闭，通知和麦克风权限尚未验收。此文不是已发布产品的安装承诺。

## 现在可用的开发切片

### 静态网页只读切片（源码 0.1.48.0，未安装）

源代码版本接受“读取网页：https://公开网站/页面”“查看网页内容 https://...”或“浏览网页 https://...”这类明确命令，仅尝试读取公开HTTPS HTML/XHTML静态正文。它不会打开用户 Edge 窗口、使用登录态、执行页面脚本、提交表单或下载文件。源码读取器已成功完成一次 `example.com` 在线静态读取；签名验证包尚未安装，因此不能把此功能作为当前安装版能力。

完整限制和当前检查结果见[公开网页静态读取边界](../架构与接口/公开网页静态读取边界.md)。

### 公网文件下载切片（实现于源码 0.1.51.0，未安装）

输入“下载文件：https://公开网站/文件名”可以尝试下载一个直接公开的文件到小K数据目录下的 `Exports` 文件夹。只支持 HTTPS 443 公网链接；不使用浏览器登录状态或系统代理，不会打开下载内容。单文件上限50 MiB，网页、可执行文件、脚本、不安全文件名和导出目录中的同名目标会被拒绝；写入后核验文件大小与 SHA-256。结果进入任务中心，不会切换当前窗口。当前只完成源码和合成响应检查，未执行真实文件下载，也尚未安装本版本。

完整边界和验收证据见[公网文件下载边界](../架构与接口/公网文件下载边界.md)。

### 本机单文件压缩切片（源码 0.1.52.0，未安装）

输入“压缩文件：完整本机路径”可把设置搜索目录里的单个普通文件压成 ZIP，写入小K数据目录下的 `Exports` 文件夹。例如“压缩文件：D:\Users\你\Documents\预算.xlsx”。单个源文件最大100 MiB；压缩包只包含原文件名对应的一个顶层条目，原文件保持不变，同名压缩包不会覆盖。源文件必须位于设置中的搜索目录；不支持目录、链接、硬链接、网络路径、备用数据流、批量压缩、解压或执行。压缩在后台进行，不会切换窗口；完成后会核对 ZIP 内的文件内容 SHA-256。结果不确定时会提示人工检查，不自动重试。

完整范围和当前验收限制见[本机单文件压缩边界](../架构与接口/本机单文件压缩边界.md)。

开发机需要 Windows 和 .NET SDK 10.0.401。本地命令如下：

    .\.tools\dotnet\dotnet.exe --version
    .\.tools\dotnet\dotnet.exe build XiaoK.sln --configuration Release --no-restore
    .\.tools\dotnet\dotnet.exe run --project tests\XiaoK.Tools.SafetyChecks\XiaoK.Tools.SafetyChecks.csproj --configuration Release --no-build --no-restore
    .\.tools\dotnet\dotnet.exe run --project src\XiaoK.Host\XiaoK.Host.csproj --configuration Release --no-build --no-restore

只检查窗口外观时，可用隔离诊断配置启动，不会读取常规设置或打开 `D:\XiaoK\Data`：

    .\.tools\dotnet\dotnet.exe .\src\XiaoK.Host\bin\Release\net10.0-windows10.0.26100.0\XiaoK.Host.dll --diagnostics-profile

该模式会把临时设置、任务数据库和隔离目录写入 `%TEMP%\XiaoK-Diagnostics-<随机ID>`；微信/QQ通知、模型推理、桌面工具与语音采集均关闭。提交任务只显示未执行提示。退出后临时目录保留，便于检查。

桌宠当前提供文本框、Ctrl+Shift+K、托盘、取消与停麦入口。展开面板中的“查找文件”“解释代码”“分析消息”“起草回复”快捷按钮会填入对应命令前缀；补充关键词或单条消息后再按“运行任务”。“解释代码：问题”会在设置中选择的项目快照里检索并返回本地说明，不改原项目、不生成补丁或运行命令；该路径已有合成安全检查，尚未接入已验收的模型权重。编程修改任务仍通过“编程任务”说明启动，审阅窗展示差异。“打开 VS Code 项目”直接调用现有应用启动流程。“切换到 Edge”“切换到微信”或“切换到 VS Code 小K项目”会尝试切换到已打开且属于允许列表的窗口；目标最小化时会恢复窗口，随后核对它是否真的处于前台。目标不存在时不会启动应用。该功能刚完成代码实现，尚未进行小K窗口切换实测。**取消任务**会停止当前任务并同时发出停麦信号；**停麦**会关闭唤醒监听并停止麦克风采集、丢弃未提交录音并保存关闭状态，不会取消桌面任务。点击“开始说话”才会启动麦克风；点击“停止并转写”后，录音在内存中转为本地识别，识别文本只填入输入框，必须由用户检查并再次点击“运行任务”。录音最长60秒；停麦、取消和退出会丢弃未提交的录音。点击“朗读反馈”才会合成本地语音并播报，随时可点“停止播报”。首次使用需要 Windows 麦克风权限；真实设备、权限提示、采集取消和扬声器播放尚未实测。分析和起草需要可用的本地推理端点；未连接时只提示本地服务不可用，不转发到云端。通过托盘选择退出时，小K会先请求取消当前任务，等待任务完成本地状态处理后再关闭；退出不会自动重放外部动作。设置页可配置用户数据、模型、评测目录、文件搜索目录、VS Code/Edge/微信/QQ本机程序和小K项目目录，以及仅限回环地址的本地推理端点。新建开发设置时，主模型根目录默认是仓库内被 Git 忽略的 `models/llm/qwen3.5-4b/<固定revision>/`；ASR/TTS 权重位于 `models/speech/` 下各自的模型版本目录。数据库、缓存和评测目录仍默认位于仓库外。搜索目录每行一个，最多20个，必须是已存在的本机目录，拒绝 UNC 和映射网络盘、盘符根目录；应用程序按固定可执行文件名校验。保存路径后重启生效。未打包开发版可以选择在当前用户登录后于托盘启动；MSIX StartupTask 状态与请求 API 已接入，签名安装、系统授权和登录恢复行为仍待实机验收。设置页可按需读取小K进程 CPU/RAM、NVIDIA 显卡系统总显存及 DXGI 统计的当前 Host 进程本地显存；该进程读数不含独立模型或语音服务进程，且需结合本机实测判断。评测目录清理会显示目标与文件数并再次确认，只处理目录顶层普通文件。文件搜索只遍历已配置的本机目录；目录项从已打开的 Windows 目录句柄枚举，子目录与匹配文件再按卷序列号、128位文件 ID 和最终路径核验，不跟随重解析点。对抗性并发替换压力测试尚未完成。允许列表中的应用启动和有限范围文件名查找已有骨架。本地推理客户端只接受回环地址；本机模型服务器未启动时会明确提示，不调用云端服务。

设置页新增“本地语音 Python 环境目录”。开发版默认指向仓库忽略的 `.tools/venvs`；安装版默认指向 `D:\XiaoK\Voice`，其中需先准备互相独立的 `asr` 与 `tts` 环境。安装版模型目录填 `D:\XiaoK\Models` 根目录，主模型位于固定的 `llm\qwen3.5-4b\<revision>` 子目录，语音权重位于 `speech\` 子目录；开发版仍可直接把模型目录设为 Qwen revision 目录。程序会随安装包携带固定模型锁清单和语音工作进程，但本次实现尚未迁移 D 盘权重或重建正式环境，因此不能据此判断安装版语音或主模型已可用。设置路径不自动开麦；只有用户点击语音功能后才会启动对应工作进程。

点击桌面窗口的“记录”按钮，或在托盘菜单选择“最近任务”，可查看最近任务的类别、状态、更新时间和隔离编程工作区路径。列表不展示任务请求正文、通知内容或模型回答；路径可复制后由用户自行检查。该页面只帮助定位保留的工作区，不会续跑、重放步骤、合并补丁或删除任务。程序意外退出时，最近持久化状态可能仍显示“规划中”或“运行中”；真实模型任务的崩溃恢复尚未验收。

“复制文件：完整本机路径”会把搜索目录中的一个普通文件复制到用户数据目录下的 `Exports` 文件夹；例如输入“复制文件：D:\Users\你\Documents\预算.xlsx”。此操作不打开资源管理器、保留原文件、不覆盖同名文件，单个文件上限100 MiB，并在完成后核对SHA-256。源文件必须位于设置中的搜索目录；不支持目录、链接、硬链接、网络路径和备用数据流。复制结果显示导出路径，失败时不会自动重试。

“压缩文件：完整本机路径”会将搜索目录中的一个普通文件压成 ZIP，并保存到 `Exports`；例如“压缩文件：D:\Users\你\Documents\预算.xlsx”。上限100 MiB，只包含一个顶层文件条目，不会覆盖现有输出，原文件不变。小K会重新读取压缩包并校验条目和内容散列；取消只在输出发布前生效。当前能力尚未安装版验收。

“重命名文件：完整本机路径 为 新文件名”会在原目录中重命名单个普通文件；例如“重命名文件：D:\Users\你\Documents\预算.xlsx 为 预算-归档.xlsx”。源文件必须在设置中的搜索目录内。只修改文件名，不移动文件；禁止路径、设备名和重解析文件，目标重名时不会覆盖。操作不打开资源管理器或抢占前台，并会核验文件身份与元数据；结果待核对时不会自动重试。

“分类文件夹：完整本机目录路径”会按文件扩展名只读统计文档、图片、视频、音频、压缩包、安装程序、代码与配置和其他文件；例如“分类文件夹：D:\Users\你\Downloads”。只检查设置中的搜索目录，最多递归5层/5,000个目录项，最多展示每类两个相对路径示例。不读取文件内容、不修改任何文件、不启动模型、不切换前台。扫描遇到链接、权限或数量限制时会提示结果可能不完整；扩展名分类不证明文件实际格式。

## 本机唤醒词（原型）

唤醒词默认关闭。要试用时，打开“设置 → 登录与能力状态”，勾选“启用本机唤醒词”并保存。只有以已安装 MSIX 身份运行、Windows 提供 `zh-CN` 本地语法且麦克风权限可用时才会启动；普通开发目录会显示原因并保持停麦。开启后支持固定短语“嗨小K”“你好小K”或“Hi 小K”。命中后小K只展开面板并停止监听；你还要点击“开始说话”，检查转写内容，再手动点击“运行任务”。启用选项会随设置保存并在小K下次启动时恢复。锁屏和按键录音期间自动暂停；托盘“停麦”会关闭唤醒开关并保存为关闭。该原型尚未在实际麦克风、语言包和电源状态下验收；低功耗、常驻资源和误唤醒率尚无实测。

## 首版计划中的用法

- 打开应用：“打开小K项目”或“打开 Edge”。
- 切换窗口：“切换到微信”或“切换到 Edge”；只切换到已打开且符合本机白名单的窗口，不存在时不会启动应用。VS Code 项目以配置目录名匹配窗口标题。
- 找文件：“查找文件 预算”。
- 复制单个文件：“复制文件：D:\Users\你\Documents\预算.xlsx”。只接受设置中的搜索目录，复制到 `<用户数据目录>\Exports`；同名文件不覆盖，单文件上限100 MiB。
- 压缩单个文件：“压缩文件：D:\Users\你\Documents\预算.xlsx”。只接受设置中的搜索目录，压缩包写到 `<用户数据目录>\Exports`；原文件保留、同名文件不覆盖，单文件上限100 MiB。
- 重命名单个文件：“重命名文件：D:\Users\你\Documents\预算.xlsx 为 预算-归档.xlsx”。只接受设置中的搜索目录，在原目录内更名且不覆盖目标。
- 移动单个文件：“移动文件：D:\Users\你\Downloads\预算.xlsx 到 D:\Users\你\Documents”。源文件和目标目录都必须在设置中的搜索范围内并位于同一卷；目标重名时拒绝，不创建目录、不覆盖文件，也不会切换前台。
- 只读分类文件夹：“分类文件夹：D:\Users\你\Downloads”。结果依据扩展名统计，不移动或复制文件。
- 只读代码检索：“解释代码：说明启动时如何加载配置”。
- 编程任务：在设置中选择项目和仓库外的隔离工作区，保存后重启小K；本地模型最多选4个文本文件生成补丁。审阅窗显示完整差异，并提供“保留补丁”“批准还原依赖并运行测试”和“批准应用补丁”三种选择。只有明确批准应用后，才会重新核对原文件与审阅补丁；任一目标文件变化时整批停止。替换失败会尝试恢复已写文件，无法确认时保留事务日志并提示人工核对，不会自动重试。依赖还原仅使用 nuget.org、包缓存位于隔离任务目录；构建目标和测试代码仍可能联网或写入其他位置，只对你信任的项目批准。真实凭证不要放在所选项目的源码中。详细范围见[隔离编程代理与工作区](../架构与接口/隔离编程代理与工作区.md)。
- 理解聊天：当前可在输入框粘贴单条消息并输入“分析消息：内容”；Windows 通知策略已接入，但私聊分类和 MSIX 授权尚未验收，因此现在不会从通知正文自动分析。
- 起草回复：不指定联系人时输入“帮我回复：对方消息”，使用简洁风格。先在设置的“联系人回复风格”中保存联系人名称和固定风格后，可输入“帮我回复给联系人名：对方消息”；没有匹配到已保存偏好时小K会停止并提示设置，不会猜联系人。风格可选择简洁、正式、友好、轻松或共情，可在设置中更新或删除。联系人名称只用于本机查找偏好，不发送给模型；消息正文仍仅发往本机模型，结果只是草稿，不会自动发送。
- 发送预览：按你的限定，QQ 只允许联系人显示名 `K`，微信只允许联系人显示名 `L`。分别输入“发送QQ给 K：正文”或“发送微信给 L：正文”，小K才会显示应用、收件人显示名和完整正文；其他联系人、跨平台名称或大小写不同的名称都会在预览前拒绝。预览窗同时标明客户端账号身份尚未核验。该白名单不是自动发送授权；禁止小K自行或随机发消息。此版本只做无附件预览，关闭预览即结束；微信/QQ发送适配器尚未接入，不会外发，也不会记成已批准。截图中的显示名尚未绑定稳定账号身份，因此后续接入实际发送前还要核实这两个联系人的客户端身份，并且每条消息仍需你确认最终平台、联系人和正文。带有“；附件：”或“;附件:”的请求会明确拒绝。

微信/QQ通知访问需要具有包身份的 MSIX 并取得 Windows 授权。签名 MSIX 已在隔离诊断模式启动并关闭；该模式关闭通知监控，不请求系统授权。当前通知来源 AUMID 和私聊/群聊格式尚未用真实客户端通知核实。设置支持经典桌面应用的非包 AUMID，但只应填写从真实 Windows 通知元数据核对出的完整值；会话归属不明时策略不会读取正文。最终启用时，无正文只提醒你手动打开会话；小K不会抢焦点、读取客户端数据库或注入进程。

## 数据与隐私

模型和推理链路只允许本机回环端点，不会把请求回退到云端。托管 llama.cpp 生命周期代码已加入，Qwen 权重与 b11259 CUDA 13.4 运行资产已校验。独立 llama-bench 确认 GPU 配置卸载33/33层，采样显存占用峰值4,378 MiB、最低空闲3,522 MiB；另有一次 ModelBroker 托管复验记录首请求冷启动6.28秒、10次热请求 p50/p95 为2.82/3.51秒、取消约0.51秒、空闲262秒后卸载及重载、退出后进程回收，运行峰值显存占用4,678 MiB。以上是单轮受控测量，不代表长期稳定、压力/OOM恢复或回答质量验收。模型目录没有 `llama-runtime.json` 时，小K只连接设置页中的手动本机服务；存在清单时会先核对固定版本与运行时/权重 SHA-256，通过后才启动，空闲4分钟停止。无效清单会阻止模型请求。通知原文、截图和录音默认不写入持久化存储。联系人回复风格保存在本机 SQLite，记录联系人名称、固定风格、用户确认来源和更新时间，设置页提供更新和删除入口；偏好迁移不改写旧 `settings.json`，新界面不再把新偏好写回该文件。聊天正文和模型草稿不随偏好保存。用户同意保存的脱敏评测样本单独放在仓库外，并可删除。开发版任务记录不保存原始请求或模型回答。

设置页的“本地存储”区域可创建 SQLite v4 数据库备份、从兼容备份恢复，并查看最近100条只读审批记录。恢复必须先选择备份并确认；小K会检查数据库版本、完整性和表结构，再为当前数据库创建旁置保护副本。恢复只覆盖任务状态、联系人回复风格偏好与有限审批审计，不会恢复或重放运行中的任务、命令或外发操作。可选择 `.sqlite3` 备份或恢复前生成的 `.bak` 保护副本；较旧架构的迁移备份不受此恢复入口支持。备份和恢复路径由用户选择，建议放在仓库外的本机磁盘并妥善保护。当前流程仅通过合成数据库验证，真实数据恢复仍未验收。

同一区域的“清理本地历史数据”会先列出数据库记录数、旧联系人偏好与桌宠坐标字段数，以及可识别的小K文件数量，再等待二次确认。确认后会清空 SQLite 中的任务、联系人偏好和审批记录，并保留迁移标记，防止旧源重新导入；还会移除当前 `settings.json` 中仅用于旧迁移的联系人偏好和桌宠坐标字段，并删除当前数据目录内精确命名的 `pet-window-position.json`、旧 `tasks.json`、小K生成的迁移/恢复备份、默认命名备份和恢复暂存文件。无关设置、相似名称文件、隔离编程工作区、评测样本、链接/只读文件不在清理范围内。用户另存到其他目录或使用自定义文件名的备份不会自动删除。合成数据回归已通过；清理和恢复尚未用真实用户数据演练。

规划中的默认数据目录为 D:\XiaoK\Data、模型目录 D:\XiaoK\Models、缓存 D:\XiaoK\Cache、评测目录 D:\XiaoK\Evaluations；实际路径需可配置。仓库设置样例见[settings.example.json](../../src/XiaoK.Host/settings.example.json)，应用设置位置为 `%LOCALAPPDATA%\XiaoK\settings.json`。
