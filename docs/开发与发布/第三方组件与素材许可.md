## 素材与权限边界

- 随包银渐层 PNG 均为小K项目自制图像，位于 `src/XiaoK.Host/Assets/Pets/`；没有复制 VPet 默认角色、美术或声音素材。
- VPet 只用于 WPF 姿态图呈现。小K自己的窗口、缩放、拖动、托盘和任务逻辑仍由 Host 管理；VPet 控件不接收鼠标命中，也不获得网络、消息、模型或工具执行能力。
- 姿态图是独立静态图像，不代表连续动画或实时三维模型。
- 新增、升级或移除组件时，先核对来源、版本、许可证与实际随包文件，再更新锁文件和本文；许可证未知时不纳入发布包。
