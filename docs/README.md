## 仓库根目录约定

GitHub 与开发工具要求以下入口文件保留在根目录或 `.github`：`README.md`、`AGENTS.md`、`CONTRIBUTING.md`、`SECURITY.md`、`.github/pull_request_template.md`。这些入口同样使用中文说明；其余项目长文档集中放在本目录。
