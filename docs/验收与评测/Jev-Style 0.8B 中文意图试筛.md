## 题集设计

评测器内固定20条人工编写的合成中文短消息，五个类别各4条：付款扣费、物流配送、账号登录、软件技术故障、其他社交/告知。每条问题和五个带中文说明的选项相同。样本涵盖重复扣款、退款、地址修改、验证码、异地登录、白屏、导出故障、邀约和一般告知等简单表达。

该题集刻意只用于早期筛查，类别边界清楚，消息简短；没有真实聊天、联系人、通知来源身份或工具授权题，也没有模糊意图、对抗文本、错别字、长上下文或多轮对话。不能拿它替代未来经过预注册并覆盖真实任务难度的中文决策评测集。

## 指标定义

- 准确率：预测标签与人工固定标签相同的比例。
- Macro-F1：五类F1的算术平均；各类样本数相同。
- 多类Brier：每题五个选项概率与one-hot真值的平方差求和，再对20题取平均；范围为0至2，越低越好。
- ECE：按模型最高选项概率分为5个等宽区间，计算各区间平均置信度与实际准确率差的加权绝对值。
- 时延：每题串行CPU推理耗时；p95使用最近秩法。
