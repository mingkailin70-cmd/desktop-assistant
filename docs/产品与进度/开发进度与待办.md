## P2 离线语音与模型

- 进度（2026-09-30）：`ModelBroker` 使用有界优先队列，最多排队128个请求；交互推理优先于后台步骤。隔离编程代理的文件选择和补丁生成现均作为独立后台步骤，每步后释放模型租约。新增可选托管 `llama.cpp b11256` 生命周期：模型调用前校验仓库外清单、固定路径和运行时/权重 SHA-256，之后才启动固定参数的本机进程；同一时刻最多一个推理租约，空闲4分钟停止进程，退出时等待租约清零并终止进程。模型子进程放入 Host 关闭即杀的 Windows Job Object，降低 Host 崩溃后遗留模型进程的风险。GPU 模式启动前要求 `expectedGpuMemoryMiB` 预算之外另有 1 GiB 空闲，模型就绪后复查余量；缺少读数或余量不足时拒绝/停止模型并返回 `LOW_VRAM`。进程不继承用户命令覆盖、代理或 `LLAMA_ARG_*` 环境变量，不启用服务器工具；运行时和权重文件以只读共享句柄锁定。没有清单时保留手动回环服务模式；存在但无效的清单会禁止推理，不静默回退。安全检查覆盖租约、固定清单和 GPU 预算策略。实际 b11256/权重尚未下载，命令行兼容性、进程启动/停止、哈希核对、预算本机校准和真实模型并发/性能仍待验收。
