# 小K项目概览与首版边界

更新：2026-09-30。小K是面向一台 Windows PC 的本地桌面宠物与助手。当前仓库已进入第一轮工程实施，有可编译的 WPF 桌面壳、安全工具骨架和隔离代码补丁生成链路；本地模型尚未部署，补丁链路未做本机运行/安全验收，尚未达到可日常使用或发布状态。完整选型和验收方案见[实施计划与模型选型](实施计划与模型选型.md)，逐项进度见[开发进度与待办](开发进度与待办.md)。

## 首版目标

首版交付必须完整验收六类场景：打开应用、找文件、隔离工作区编程、理解聊天、起草回复、确认后发送。微信和 QQ 同时支持全部新私聊通知；只有来源和私聊归属确认、正文可见、系统授权有效、用户会话解锁时自动在本机分析。正文缺失时只提示用户手动打开会话，不会自动切换窗口。聊天正文仅临时处理，不默认写入日志或任务数据库。

开发任务使用本地模型，不调度 Codex。推理无云端回退；微信/QQ本身发送消息仍依赖其正常联网。每次发送先展示最终收件人、正文和附件并等待用户确认。

## 本机与模型方向

设计目标机器为 Intel Core Ultra 9 275HX、32 GB RAM、RTX 5060 Laptop 8 GB 和 Intel 集显。主模型首测 Qwen3.5-4B Q4 + 固定版本 llama.cpp；MiMo-V2.6-Distill-Qwen-9B 已下载为 P0 离线资源/代码对照候选，不作为常驻模型；独立开源 JEV-9B/JEV-27B 仍属后续评估候选。Qwen3.8 目前官方开放型号起步为27B，不适合本机资源；Qwen-Image-2.1 是带研究许可的图像生成/编辑模型，不属于对话主模型。主模型、ASR、TTS、MiMo 四组权重共35个文件、25,954,040,709字节，已下载并校验散列；llama.cpp b11259 CUDA 13.4 运行包已校验并暂存，用户接受本机 CUDA 许可后完成两次 Qwen 合成推理；Python语音依赖仍未部署，CUDA实际卸载、峰值显存、标准延迟、模型效果与硬件资源仍需本机P0验收。桌宠空闲新增独显显存目标低于300MiB，剩余独显显存至少约1GiB。

TypeSafe Jev/`jev-ultrafast` 依赖云端服务，首版不接入；JEV-9B 与 JEV-27B 是独立开源学生模型，待P5离线评估。Laya、Fara 与 RSI 同属首版后的候选研究方向，不能绕过 ToolBroker 固定权限。更多选型和验收方法见[实施计划与模型选型](实施计划与模型选型.md)。

## 安全原则

- 屏幕、通知、文件和模型输出都按不可信数据处理。
- 工具执行受固定白名单、权限、目标重核和独立结果核验限制。
- 本地编程代理的路径仅来自用户设置，只把受限文件送入本地模型，补丁只写入隔离副本。一个固定 .NET 依赖还原/测试配方需在审阅差异后单独批准，并在 Windows AppContainer 内运行：任务工作区可写、固定运行时只读；测试步骤不配置网络能力，还原步骤配置 `internetClient` 且 NuGet 源限定为 nuget.org。合成离线探针已验证兄弟目录哨兵不可读写，以及超时和取消会终止进程；真实项目构建/测试和网络边界仍待验收。常见凭证文件与若干密钥格式会被排除，但扫描尚未证明完整；不能据此认定所有副作用为零。
- 外发、删除、支付、管理员操作需明确预览和用户确认；结果未知时人工核对，不自动重发。
- 模型、数据库、缓存和可删除评测数据放在 D 盘、仓库之外。

## 阶段

| 阶段 | 目标 |
| --- | --- |
| P0 | 验证微信/QQ通知正文与私聊归属，建立中文模型/语音/代码任务集和GPU基线。 |
| P1 | 桌宠、托盘、文本、快捷键、停麦/取消、登录启动和长期运行。 |
| P2 | 全本地唤醒、ASR、LLM、TTS。 |
| P3 | 应用/文件/浏览器/消息工具、安全审批、隔离代码代理。 |
| P4 | 六类场景全验收，完成安装、通知授权、恢复、回滚与隐私清理。 |
| P5–P6 | 首版后比较候选模型并研究受控 RSI。 |

P0 任一发布门槛未达成时暂停发布，提交失败样本与资源数据后再决定产品范围或硬件。
